핵심 파이프라인 구현 내용
------------------------
mesh_pipeline.py에 다음 기능을 구현했다.

- STL 로드
  - trimesh로 STL을 로드
  - Scene으로 로드되면 geometry를 하나의 mesh로 합침
  - STL 특성상 중복 정점이 많은 문제를 줄이기 위해 merge_vertices 적용

- STL 검사
  - triangle_count
  - vertex_count
  - watertight
  - winding_consistent
  - boundary_edges
  - non_manifold_edges
  - volume_available
  - volume

- 출력 가능성 판단
  - triangle_count > 0
  - boundary_edges == 0
  - non_manifold_edges == 0
  - watertight == True

- PyMeshLab repair
  - duplicate faces 제거
  - duplicate vertices 제거
  - unreferenced vertices 제거
  - null/degenerate faces 제거
  - non-manifold edges repair
  - non-manifold vertices repair
  - holes close
  - coherent face orientation
  - PyMeshLab 버전별 필터명 차이를 고려해 safe_apply 방식으로 처리

- MeshFix fallback
  - PyMeshLab 후에도 출력 가능 상태가 아니면 pymeshfix.clean_from_file 실행

- Open3D simplify
  - duplicated vertices 제거
  - duplicated triangles 제거
  - degenerate triangles 제거
  - unreferenced vertices 제거
  - non-manifold edges 제거
  - 기준 triangle 수를 넘으면 quadric decimation 수행

- Floating regions 검사/정리
  - connected components로 본체와 분리되어 bed 위에 떠 있는 조각 탐지
  - 아주 작은 떠 있는 분리 조각만 자동 제거
  - 큰 조각이나 모델의 중요한 일부로 보이는 영역은 억지로 삭제하지 않음
  - 아래 방향 면/오버행 비율을 계산해 support_recommended 값을 report에 기록

추가 안정성 수정
----------------
- input 파일 경로가 없으면 친절한 오류 메시지 출력
- output, reports 폴더 자동 생성

Simplify 파라미터
-----------------
기본값은 mesh_pipeline.py 상단에 모아두었다.

- DEFAULT_SIMPLIFY_THRESHOLD = 300_000
  - triangle count가 이 값을 넘으면 simplify를 시도한다.

- DEFAULT_TARGET_TRIANGLES = 180_000
  - simplify 시 이 정도 triangle count를 목표로 줄인다.

예시:
- 250,000 triangles: simplify 안 함
- 500,000 triangles: 약 180,000 triangles로 줄이기 시도

실행 시 임시 변경 옵션:
- --simplify-threshold
- --target-triangles
- --floating-bed-tolerance
- --floating-remove-ratio

예:
python process_stl.py input/test.stl --simplify-threshold 500000 --target-triangles 250000
python process_stl.py input/test.stl --floating-bed-tolerance 0.1 --floating-remove-ratio 0.002
